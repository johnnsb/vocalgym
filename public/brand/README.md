# Brand assets

The `<BrandMark>` component (`components/ui/BrandMark.tsx`) expects these
pre-colored transparent PNGs, exported from the "VocalGym Design System" Claude
Design project (assets/ folder):

    logo-lockup.png            logo-lockup-inverse.png     logo-lockup-ember.png
    logo-mark.png              logo-mark-inverse.png       logo-mark-ember.png
    logo-wordmark.png          logo-wordmark-inverse.png

They exceed the 256 KiB design-tool read cap, so drop them here manually.
Until then `<BrandMark>` renders a broken-image box.
